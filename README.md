# 📈 股票学习路线跟踪系统

适合新手的A股入门学习进度跟踪工具，针对2-3w小资金设计。

## ✨ 功能特点

- ✅ **学习进度打卡** - 三个阶段18个任务，点击即可标记完成
- 📊 **实时进度条** - 可视化显示学习进度百分比
- 💰 **资金配置建议** - 针对2-3w新手的资金分配参考
- 📚 **学习资源链接** - 精选入门学习资源和工具网站
- 📈 **推荐ETF列表** - 新手首选的4只宽基ETF
- ⚠️ **避坑提醒** - 新手最容易踩的6个大坑

## 🚀 使用方法

### 方法一：静态HTML版（推荐）
直接下载 `stock-learning.html` 到本地，双击用浏览器打开即可。
- 进度自动保存在浏览器本地存储
- 无需服务器，无需网络（除了访问外部链接）

### 方法二：Flask服务版
```bash
# 安装依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 启动服务
python app.py
# 或
./start.sh
```
访问：`http://localhost:8000`

## 📋 学习路线

### 第一阶段：基础扫盲（1-2周）
- 学习K线、成交量、均线基本概念
- 了解A股交易规则
- 理解PE、ROE等基础财务指标
- 开通模拟盘并操作5次以上
- 阅读《小狗钱钱》建立理财思维

### 第二阶段：建立认知（2-4周）
- 学习价值投资基础
- 学习技术分析基础
- 开通A股证券账户
- 入金3000元，购买第一只ETF
- 记录每笔交易的买卖理由
- 阅读《日本蜡烛图技术》

### 第三阶段：形成策略（1-3个月）
- 学习ETF定投策略并实践
- 尝试龙头股逢低买入策略
- 学习网格交易策略
- 完成10笔以上真实交易
- 总结适合自己的交易方法
- 逐步加大资金到1-2w

## 💡 投资原则

> **不亏 > 少赚 > 稳定赚**

- ❌ 不要频繁交易，手续费吃掉利润
- ❌ 不要追涨杀跌，涨了才买，跌了就割
- ❌ 永远不要满仓操作，至少留20%现金
- ❌ 不要听消息炒股，抖音/群里的"老师"都是坑
- ❌ 绝对不要加杠杆（融资融券、配资）
- ❌ 远离ST股、妖股、次新股，风险极高
